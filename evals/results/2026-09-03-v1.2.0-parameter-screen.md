## Coverage added

The reasoning-effort interface now covers the current GPT-5.6 axis: `none`, `low`, `medium`, `high`, `xhigh`, and `max`. A one-pair exploratory sweep exercised all six settings on `waveform-first-divergence` with the same 600-second run budget, serialized outer isolation, and the final ab8 payload. It was intentionally treated as a defect-discovery screen rather than a score.

The local CompileManifest integration test now executes widths `1`, `2`, `7`, `31`, and `64`. At every point, the same parameterized design passes Icarus simulation, Verilator compiled simulation, and Yosys synthesis; the test also checks the backend-specific parameter arguments and shared input identity.

## Defects found and repaired

1. The evaluator omitted the documented `none` and `max` reasoning settings. One centralized tuple now drives the CLI choices, with a contract regression.
2. Codex `request timed out` reconnects and terminal HTTPS-fallback items were not classified as transport failures. One shared classifier now handles top-level and completed-item error forms, tracks whether later progress recovered the connection, and feeds both trace parsing and the live 120-second stall monitor.
3. The workflow auditor treated a non-executing `codex --help` probe as a nested agent invocation. Pure help/version probes are now permitted; `codex exec`, interactive launch, and equivalent Python module execution remain prohibited.

Historical raw traces were replayed through the repaired classifier. The old `low` off/on, `high` off/on, and `medium` off samples end in terminal network failure and are excluded. The old `xhigh` on sample records later progress after reconnect and remains a valid task timeout, but it cannot be combined with final-harness reports.

Fresh post-repair runs demonstrated fail-fast behavior: two `low` attempts, one `gpt-5.6-terra` medium attempt, and the first final-harness `none` attempt all terminated as infrastructure failures before a complete pair. Each stopped the exact cgroup, emitted no aggregate report, recorded zero swap/OOM/memory-limit events, and left no evaluator process or systemd scope. A fresh pre-final-freeze `high` pair completed correctly and exposed no Skill defect, but its earlier harness identity prevents inclusion in the final matrix.

## Required continuation

Resume only after the Codex transport is stable. Keep the final harness and ab8 payload immutable while executing these stages:

1. Screen all six reasoning efforts with one pair each on the waveform case.
2. At the best valid effort, screen `gpt-5.6-sol`, `gpt-5.6-terra`, and `gpt-5.6-luna` on waveform, SystemVerilog signed-width repair, and synthesis-linked STA.
3. Select configurations by the Pareto set of correctness, deliverable completeness, current structured evidence, workflow compliance, timeout rate, latency, input/output tokens, and resource peaks. Do not use a weighted score.
4. Run five fresh pairs per retained configuration and task class. Report per-task Wilson intervals and paired outcomes; cross-task totals remain descriptive.
5. Separately extend semantic graders across width/depth corners so model-quality conclusions are not based on one parameter value.

Monetary cost is not embedded in the evaluator. If reported, it must use a separately dated official price source and preserve the directly observed token counts.
