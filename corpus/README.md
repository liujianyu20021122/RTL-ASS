# Quarantined corpus manifests

`upstream-sources.json` records immutable Git revisions, automated license findings, RTL/SystemVerilog/TB path counts, and benchmark-contamination signals for locally downloaded research sources.

The manifest does not redistribute upstream code and does not mark any source as trusted. Automated license classification is only a screening result; a compatible license and provenance review are required before publishing distilled records. Benchmark-like content must remain outside retrieval namespaces used to evaluate RTL-ASS.
